# HandGestureAI-ML

An AI-powered hand gesture recognition system built using Python and TensorFlow, exploring deep learning, computer vision, neural network training, and TensorFlow Lite model deployment.

## Overview

This project focuses on developing a custom machine learning system for hand gesture recognition.

It uses trained deep learning models to process hand images, extract landmark-based features, and classify hand gestures through a neural network.

The project covers the complete machine learning workflow, from image preprocessing and feature extraction to model training, evaluation, and TensorFlow Lite conversion.

## Key Features

- Custom deep learning model development
- Hand landmark detection and coordinate extraction
- Landmark normalization and feature processing
- Neural network-based gesture classification
- Dataset preprocessing and batch processing
- Model training and validation
- Performance evaluation using accuracy, loss, and confusion matrix
- TensorFlow Lite conversion and model comparison

## Machine Learning Workflow

1. **Image Processing:** Prepare input images for landmark detection.
2. **Landmark Detection:** Identify hand keypoints using the trained landmark model.
3. **Feature Extraction:** Decode and normalize landmark coordinates into numerical features.
4. **Model Training:** Train a neural network to recognise hand gestures.
5. **Model Evaluation:** Analyse training performance and validation results.
6. **Model Conversion:** Convert trained Keras models into TensorFlow Lite format.
7. **Conversion Validation:** Compare original and converted model predictions to verify conversion consistency.

## Model Deployment

The trained models are converted into TensorFlow Lite format to support lightweight and efficient inference on supported platforms.

## Dataset

The project uses a custom-processed hand gesture image dataset for model development and evaluation.

The original image dataset is not included in this repository due to its size.
